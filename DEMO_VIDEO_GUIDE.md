# 🎥 Demo Video Guide

Instructions for creating and uploading your LUMEN demo video for the hackathon submission.

---

## 📋 Video Requirements

### Technical Specs

-   **Duration**: 3-5 minutes (max 8 minutes)
-   **Resolution**: 1920x1080 (1080p minimum)
-   **Format**: MP4, MOV, or WebM
-   **Audio**: Clear voiceover or background music
-   **Frame Rate**: 30 fps or 60 fps
-   **File Size**: Under 500 MB for easy upload

### Content Requirements

-   Show all key features
-   Demonstrate real workflow
-   Highlight AI capabilities
-   Show problem → solution
-   Include contact/team info

## 🎥 Recording Tips

### Before Recording

1. **Clean your desktop** - Hide unnecessary icons/files
2. **Close unnecessary apps** - Reduce notifications
3. **Prepare test data** - Use realistic invoice examples
4. **Practice walkthrough** - Know your flow
5. **Test audio** - Check microphone levels
6. **Set up lighting** - If showing camera

### During Recording

1. **Speak clearly** - Enunciate, not too fast
2. **Mouse movements** - Smooth, deliberate
3. **Highlight clicks** - Use cursor highlighting
4. **Pause between sections** - Easier to edit
5. **Show, don't just tell** - Demonstrate features
6. **Handle errors gracefully** - If something breaks, acknowledge and continue

### Recording Checklist

-   [ ] Audio is clear (test recording)
-   [ ] Screen resolution set to 1920x1080
-   [ ] Browser zoom at 100%
-   [ ] Hide bookmarks bar (Ctrl+Shift+B)
-   [ ] Full screen mode when appropriate (F11)
-   [ ] Disable notifications
-   [ ] Close extra browser tabs
-   [ ] Ensure good internet connection (if showing live API calls)
-   [ ] Have backup clips ready
-   [ ] Record multiple takes if needed

## 📤 Uploading to YouTube

### Step 1: Prepare

1. Create title:

    ```
    LUMEN - AI-Powered Invoice Management | Hack-a-Sol @ IIIT Naya Raipur
    ```

2. Write description:

    ```
    LUMEN is an intelligent invoice management system built by Team
    dUnder Pressure for the Hack-a-Sol Hackathon at IIIT Naya Raipur.

    🚀 Features:
    • 95%+ accurate OCR extraction
    • AI-powered analytics and forecasting
    • Natural language query interface
    • Anomaly detection and fraud prevention
    • Cost-saving recommendations

    🛠️ Tech Stack:
    • Next.js & TypeScript (Frontend)
    • Flask & Python (Backend)
    • Google Cloud Vision (OCR)
    • OpenRouter LLM (AI)
    • PostgreSQL & ChromaDB (Data)

    📚 Documentation & Source Code:
    https://github.com/CoderUzumaki/Lumen

    👥 Team dUnder Pressure:
    [List team members]

    🏆 Built for: Hack-a-Sol Hackathon
    🏫 Institution: IIIT Naya Raipur
    📅 Date: November 2025

    #hackathon #ai #machinelearning #invoicemanagement #fintech
    ```

3. Add tags:

    ```
    hackathon, AI, machine learning, invoice management, OCR,
    fintech, IIIT Naya Raipur, Hack-a-Sol, automation,
    natural language processing, analytics, forecasting
    ```

4. Create thumbnail:
    - 1280x720 pixels
    - Include LUMEN logo
    - Show key feature
    - Add text: "AI Invoice Management"

### Step 2: Upload

1. Go to [YouTube Studio](https://studio.youtube.com)
2. Click "Create" → "Upload video"
3. Select your video file
4. Fill in title, description, tags
5. Add thumbnail
6. Set visibility:
    - **Public** for hackathon submission
    - **Unlisted** if you want only link access
7. Add to playlist (create "Hackathon Projects")
8. Click "Publish"

### Step 3: Update README

1. Copy YouTube video URL
2. Extract video ID from URL:
    ```
    https://www.youtube.com/watch?v=ABC123XYZ
                                     ↑
                               This is the ID
    ```
3. Update README.md:
    ```markdown
    Replace: YOUR_VIDEO_ID
    With: ABC123XYZ
    ```

## 💡 Pro Tips

1. **Keep it concise** - Respect viewers' time
2. **Show real data** - Use realistic examples
3. **Highlight uniqueness** - What makes LUMEN special?
4. **Tell a story** - Problem → Solution → Impact
5. **End with CTA** - Invite viewers to try it/contribute
6. **Add enthusiasm** - Show your passion for the project
7. **Quality over quantity** - 3 minutes of great content > 8 minutes of filler
8. **Test on multiple devices** - Verify it looks good everywhere
9. **Get feedback** - Have team review before publishing
10. **Include timestamps** - In description for long videos
