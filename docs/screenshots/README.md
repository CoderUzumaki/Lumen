## How to Add Screenshots

1. Take screenshot of the feature
2. Save as PNG with descriptive name (e.g., `dashboard-main.png`)
3. Place in `docs/screenshots/` directory
4. Screenshot should show:
    - Full browser window or relevant section
    - Real/realistic data (no Lorem Ipsum)
    - Proper lighting/contrast
    - No personal information

## Screenshot Guidelines

-   **Resolution**: 1920x1080 or higher
-   **Format**: PNG (for UI), JPG (for photos)
-   **Size**: Optimize to < 500KB per image
-   **Content**: Use realistic mock data
-   **Privacy**: No real user information
-   **Quality**: Clear, sharp, well-lit screenshots
