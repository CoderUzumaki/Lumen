## 📝 Documentation Standards

All documentation in this project follows these standards:

### Formatting

-   **Markdown**: All docs use Markdown (.md)
-   **Headings**: Hierarchical structure (H1 → H6)
-   **Code blocks**: Language-specific syntax highlighting
-   **Tables**: For structured data
-   **Lists**: Bullet points or numbered lists
-   **Links**: Relative links between docs

### Style Guide

-   **Tone**: Professional but friendly
-   **Language**: Clear, concise, active voice
-   **Examples**: Practical, working examples
-   **Structure**: Logical flow with TOC for long docs
-   **Emoji**: Used sparingly for visual hierarchy
-   **Screenshots**: High quality, annotated where helpful

### Maintenance

-   **Updates**: Keep in sync with code changes
-   **Reviews**: Regular documentation audits
-   **Feedback**: Incorporate user feedback
-   **Versions**: Document version-specific features
